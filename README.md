# toeic-words

경선식 토익영단어 2190개를 강의 mp3와 묶어 듣는 정적 웹앱.

## 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전부. 강 선택(복수) → 단어 목록 → 재생 |
| `words.json` | 2190개. `seq`(학습가이드 색인 순서) / `lesson` / `word` / `meaning` |
| `segments.json` | 위에 `file` / `start` / `end` 오프셋 추가. 2092개 |
| `mp3/` | 강별 음원 88개. 32kbps 모노로 재인코딩 (원본 353MB → 59MB) |
| `serve.py` | 로컬 개발용 서버. Range 지원 |
| `tools/` | 원본 자료에서 위 json을 만드는 스크립트, 검사 |

## 세 가지 모드

- **듣기** — 강을 여러 개 골라 진도 순서로 이어듣기. `2회` 반복, `단어만`(뜻 빼고 영단어만)
- **퀴즈** — 한 문제씩. 단어→뜻 / 뜻→단어를 문항마다 무작위로
- **시험** — 문제 수와 형식(객관식/주관식/섞어서)을 고르고 전부 한 화면에. 채점하면 100점 만점 점수

## 주관식은 어떻게 채점하나

뜻 문자열을 후보로 쪼개서 **하나만 맞아도 정답**으로 본다.

```
n. 1. 몫, 지분, 주식 2. 공유하다, 나누다  →  몫 / 지분 / 주식 / 공유하다 / 나누다
주의[경고]를 주다                        →  주의를주다 / 경고를주다
(~에) 속하다                             →  속하다
```

뜻 번호(`2.`)는 지우지 않고 구분자로 바꾼다. 지우기만 하면 `주식 2. 공유하다`가
`주식공유하다` 한 덩어리가 된다.

부분일치는 '포함'이 아니라 **앞에서부터**만 인정한다. 포함으로 하면 `하다` 한 방에
공유하다·제공하다가 전부 정답이 되어버린다.

**유의어(걷다 ↔ 걸어가다)는 자동으로 못 잡는다.** 한국어 유의어 사전이 없고, 글자
유사도로는 안 걸린다. 그래서 자동으로 안 걸린 답은 정답을 보여주고 사용자가 직접
O/X 를 뒤집는다. 오답을 정답으로 넘기는 실수가 그 반대보다 나쁘다는 판단.

## 검사

```
node tools/check-quiz.mjs   # 퀴즈 보기 충돌 (전체 단어 × 3회)
node tools/check-exam.mjs   # 주관식 자동 채점
python3 serve.py --check    # Range 파싱
```

## 로컬 실행

```
python3 serve.py          # http://localhost:8765
python3 serve.py --check  # Range 파싱 점검
```

`python3 -m http.server` 는 쓰면 안 된다. Range 요청을 무시해서 브라우저가 mp3 중간으로
seek을 못 하고 매번 0초부터 재생된다.

## 오디오를 어떻게 잘랐나

강별 mp3는 통 녹음이 아니라 단어별 클립을 이어붙인 것이고, 클립 사이에 정확히 1.0초
디지털 무음이 들어 있다. 단어 내부(영단어↔뜻 사이) 최장 쉼은 0.74초라 -70dB 기준으로
깨끗하게 갈린다. 강별 단어 수를 알고 있으므로 "가장 긴 무음 n-1개"를 경계로 삼는다.

파일을 2190개로 자르지 않고 오프셋만 저장한다. 강당 파일 하나만 받으면 되고, 경계가
틀리면 `segments.json` 숫자만 고치면 된다.

## 재생성

원본 자료(`word.xls`, `학습가이드.pdf`, 원본 `mp3/`)는 저작권 때문에 저장소에 없다.
상위 디렉토리에 두고 실행한다.

```
python3 tools/build_words.py      # 학습가이드 색인 순서로 words.json
python3 tools/build_segments.py   # 무음 검출로 segments.json
```

## 알려진 구멍

- **78강, 79강 mp3 없음** — 원본에 파일이 빠져 있다. 단어 데이터는 `words.json`에 있고
  `segments.json`에만 빠져 있다 (2190 → 2092)
- **38강, 41강** — 클립 내부에 0.96초 무음이 하나 더 있어 경계 판정 여유가 0.02초다.
  나머지 86강은 0.04초 이상. 이 두 강은 귀로 확인 필요
- 같은 강에 같은 단어가 뜻만 다르게 여러 번 나오는 경우가 38개 있다 (`raise`, `charge` 등).
  학습가이드에도 단어만 적혀 있어 이들끼리의 내부 순서는 구분되지 않는다
